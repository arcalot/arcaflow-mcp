## Getting started

This guide provides quick pointers for local and server mode usage.

### Local mode (stdio)

Local mode is intended for desktop MCP clients that spawn the server on demand.
See `docs/arcaflow-mcp/usage/local-mode.md` for client configuration guidance.

### Server mode (HTTP/SSE)

Server mode exposes HTTP POST plus an SSE stream with session binding. See
`docs/arcaflow-mcp/usage/server-mode.md` for endpoint details and examples.
